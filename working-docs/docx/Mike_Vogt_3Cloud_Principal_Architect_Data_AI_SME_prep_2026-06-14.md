## 2. Role Reality: What This Job Actually Is

This is a **pre-sales technical SME** embedded alongside account executives — not a delivery architect, not a practice manager. Key reality checks:

| What the JD says | What it means in practice |
|------------------|--------------------------|
| "Technical evangelist and trusted advisor" | You're the technical credibility on sales calls — AE brings you in when the client needs more than a slide deck |
| "Partner with sales and account teams to drive deal closure" | Quota-adjacent (possibly quota-carrying) — your success is measured in pipeline influence and $500K+ wins |
| "Lead technical discoveries" | First substantive client meeting — you define what they need before engineering ever touches it |
| "Innovation workshops, POVs" | Time-boxed engagements designed to de-risk the buy decision and build a funded implementation case |
| "Mentor architects and data scientists" | You're also the floor ceiling for delivery quality — SME means delivery teams call you when they're stuck |
| "Stay current on Microsoft Data & AI roadmaps" | You'll be doing competitive positioning: Fabric vs. Databricks, Azure AI Foundry vs. AWS Bedrock, etc. |

**This is exactly what you've been doing at AHEAD and SPR.** The framing difference: AHEAD embedded this in a delivery consulting model; 3Cloud makes it a dedicated role with a sales partnership.

## 7. Technical Topics to Be Ready to Discuss (Not Deep-Dive — Fluency Level)

### Microsoft Fabric
- OneLake as unified storage layer (replaces ADLS Gen2 silos)
- Fabric items: Lakehouses, Warehouses, Pipelines, Notebooks, Dataflows Gen2, Real-Time Analytics (KQL), Power BI Premium Direct Lake mode
- Where Fabric wins vs. Databricks: M365 integration, Power BI native, single platform licensing model
- Where Fabric isn't yet: production-grade MLOps, complex Spark workloads, ISV ecosystem maturity
- Migration path: "Lift and shift" from Synapse Analytics → Fabric

### Azure Synapse Analytics (legacy context)
- Understand it's being sunset/absorbed by Fabric — clients still running it; migration is a 3Cloud opportunity

### Databricks on Azure
- Unity Catalog for governance (vs. Purview — often complementary)
- Delta Lake, Delta Live Tables, MLflow
- When to recommend Databricks over Fabric: ISV-heavy shops, Spark-first teams, multi-cloud data architectures, advanced ML workloads

### Azure AI Stack
- **Azure AI Foundry** (formerly Azure AI Studio): hub for building generative AI apps, fine-tuning, model deployment
- **Azure OpenAI Service**: GPT-4o, GPT-4 Turbo, embeddings — governed enterprise access
- **Azure ML**: MLOps platform — experiment tracking, pipelines, endpoints, managed compute
- **Prompt Flow**: orchestration layer for LLM chains; competes with LangChain
- **Microsoft Copilot Studio**: power-user copilot building; not engineering-grade
- **RAG pattern on Azure**: Azure AI Search (vector + keyword hybrid) + Azure OpenAI + Azure Blob/ADLS

### Data Governance on Azure
- **Microsoft Purview**: unified data catalog, lineage, classification, RBAC/ABAC — ties into Fabric natively
- Key message: governance is the unlock for AI adoption — ungoverned data = ungoverned AI

| Avanade | Avanade is Microsoft + Accenture; both are Azure-heavy. 3Cloud differentiator: Azure Expert MSP (audited) + Elite Databricks + Partner of the Year for Data & AI. Avanade wins on scale; 3Cloud wins on depth and speed |
| Slalom | Multi-cloud generalist consultancy. 3Cloud = Azure-native engineering depth, not advisory-only |

| Microsoft own field (CSU) | Microsoft co-sells; 3Cloud (now Cognizant) implements. Complementary — and Cognizant has deep Microsoft co-sell relationships |
| Cognizant (parent) | The Azure/AI depth play within Cognizant's broader digital portfolio — 3Cloud brings the Azure Expert MSP credential and 1,500+ certs that the rest of Cognizant doesn't have |

## 9. Questions to Ask Them

These signal seniority and genuine interest — ask 3-4, not all:

3. **"How has the Telefónica Tech acquisition changed the go-to-market or deal flow — are you seeing larger enterprise deals, or more international co-sell?"** *(Shows you did your homework on the acquisition)*

4. **"What does the mentoring expectation look like for delivery architects — is the SME embedded in delivery at all, or is it a clean handoff?"** *(Shows you understand team dynamics)*

5. **"Where do you see the biggest whitespace opportunity in the Data & AI practice right now — is it Fabric migration, AI Foundry / RAG patterns, or something else?"** *(Shows strategic curiosity and lets them sell you on growth)*

6. **"What does success look like in the first 90 days for this role?"** *(Classic, but genuinely useful)*
