## Setup Instructions

### Backend Setup

1. **Activate virtual environment:**
   ```bash
   cd /home/mike/models/source/hybrid-ai-windows/applications/resume-optimizer
   source .venv/bin/activate
   ```

2. **Verify dependencies installed:**
   ```bash
   pip list | grep -E "Flask|spacy|nltk"
   ```

3. **Start Flask backend:**
   ```bash
   cd backend
   python app.py
   ```
   Backend will run on: http://localhost:5000

### Frontend Setup

1. **Install Node dependencies:**
   ```bash
   cd frontend
   npm install
   ```

2. **Start React development server:**
   ```bash
   npm start
   ```
   Frontend will run on: http://localhost:3000

## API Endpoints

- `POST /api/register` - Create new user
- `POST /api/login` - Authenticate user
- `POST /api/upload/resume` - Upload resume file
- `POST /api/upload/job-description` - Submit job description
- `POST /api/optimize` - Optimize resume for job
- `GET /api/history` - Get optimization history
- `GET /api/resume/:id` - Get resume details
